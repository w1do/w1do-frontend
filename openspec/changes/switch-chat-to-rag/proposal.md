## Why

ИИ-консультант (изменения `add-ai-chat-page`, `add-chat-lead-widget`) отвечает по каталогу услуг и FAQ, которые `system-prompt.ts` собирает из `getServices()` и целиком кладёт в системный промпт. Каталог ограничен 12 000 символов, в нём нет блога, тарифов и инструкций, а модель может домысливать. У компании есть RAG-сервис Vector (`RAG_API_URL`), в который загружены материалы сайта. Ассистент должен искать сведения только там, ничего не выдумывать и быть очень дружелюбным.

Сейчас чат есть только на `/chat` и в слоте формы блока `Cta`. Нужен плавающий ассистент внизу экрана на всех страницах сайта, который сам открывается при первом заходе.

## What Changes

- Источник знаний ассистента — только RAG API (`POST {RAG_API_URL}/context`). Каталог услуг и FAQ из промпта убираются.
- На каждый ход сервер ищет фрагменты по вопросу посетителя и передаёт модели (PolzaAI) только найденный контекст. Модель отвечает строго по нему. Если сведений нет — честно говорит об этом и предлагает оставить заявку.
- Новый тон: тёплый, дружелюбный, на «вы», коротко.
- Новые серверные переменные: `RAG_API_URL`, `RAG_API_KEY`, `RAG_PROJECT_ID`.
- Новый плавающий ассистент: кнопка внизу справа на всех страницах, кроме `/chat`. Окно открывается само один раз за сессию браузера.
- Сбор заявки в диалоге (согласие, карточка, `/api/chat-lead`), Redis, лимиты и блокировки остаются без изменений.
- Встроенный виджет в `Cta` и страница `/chat` остаются и работают на том же RAG-бэкенде.

## Non-goals

- Наполнение и переиндексация RAG (`/sources/*`, `/reindex`) — делается в админке Vector.
- Потоковая выдача ответа (streaming).
- Общая история диалога между плавающим окном и встроенным виджетом.
- Изменение контракта `/api/lead` и `/api/chat-lead`.

## Capabilities

### New Capabilities

- `rag-assistant`: ответы ассистента только по RAG и плавающее окно ассистента.

### Modified Capabilities

- `ai-chat` (из `add-ai-chat-page`): источник знаний меняется с каталога услуг на RAG.
