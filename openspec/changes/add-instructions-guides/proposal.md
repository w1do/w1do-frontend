## Why

На сайте нет раздела с пошаговыми обучающими гайдами («как настроить Claude Code», «как сделать туннелирование»): материалы либо лежат в блоге как статьи, либо отсутствуют. Нужен отдельный раздел «Инструкции» с рубриками, карточками и страницей полного гайда, доступный из шапки сайта.

## What Changes

- В CMS W1DO создаётся коллекция `guides` с полями: заголовок, краткое описание, рубрика (select, filterable) + slug рубрики, обложка, тело гайда (rich_text), SEO-поля; публикуются первые записи.
- На фронте появляется раздел `/instructions`: индекс-страница с левым сайдбаром рубрик и сеткой карточек гайдов справа.
- Страница рубрики `/instructions/<rubric>` фильтрует карточки по выбранной рубрике (тот же сайдбар, активная рубрика подсвечена).
- Страница гайда `/instructions/<rubric>/<slug>` показывает полный текст гайда; 404 — для несуществующих и снятых с публикации записей.
- В `Header.astro` добавляется пункт меню «Инструкции» → `/instructions`.
- Новый серверный адаптер `src/lib/server/w1do/guides.ts` читает коллекцию через существующий публичный API (`/api/v1/content/collections/guides/entries`), новых эндпоинтов не вводится.
- Новые маршруты включаются в общий sitemap (`src/lib/server/full-sitemap.ts`), хлебные крошки учитывают новые адреса.

## Capabilities

### New Capabilities

- `instructions`: раздел «Инструкции» — индекс с сайдбаром рубрик и карточками, страница рубрики, страница полного гайда, пункт меню в шапке.

### Modified Capabilities

(нет — существующие спеки не меняются; блог, кейсы и OpenSource продолжают работать как раньше)

## Impact

- **Коллекции/файлы**: `src/pages/instructions/` (index, `[rubric]/index`, `[rubric]/[slug]`), `src/components/instructions/` (сайдбар рубрик, карточка, сетка), `src/lib/server/w1do/guides.ts`.
- **Правки существующего**: `src/components/shared/Header.astro` (пункт «Инструкции»), `src/lib/server/full-sitemap.ts` (включение новых маршрутов в общий sitemap).
- **CMS W1DO**: новая коллекция `guides` (создание через MCP, требует «да» пользователя), поля и первые записи — структура до наполнения, публикация отдельным действием.
- **Зависимости**: только существующий API W1DO (`X-Api-Key`, `locale=ru`), новых внешних зависимостей нет.
- **Риск**: пока в CMS нет опубликованных записей, раздел отдаёт пустой список с дружелюбным состоянием (как `/opensource`).
